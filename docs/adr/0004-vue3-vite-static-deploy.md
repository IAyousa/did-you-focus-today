# 迁移至 Vue 3 + Vite 静态部署，取代「双击即用单文件」约束

产品目标从"本机自用的督促工具"升级为"部署到网上可公开访问的作品集项目 + 自己随处可用"（用户 2026-09-09 拷问轮决议：零后端静态部署；学习/作品集优先，有用户是 bonus；差异化为"不可贿赂的监工"）。部署需要构建链，与单文件双击即用互斥，故取代 ADR-0001 中的交付形态约束。

决定：Vue 3 + Vite + 先用 JS（不用 TS，等类型系统真实发挥价值再引入），状态管理用组合式函数（composables）而非 Pinia——痛了再上；新工程放本仓库 `app/`；localStorage 的键与数据 schema 原样沿用（既有打卡数据零迁移）；零后端——数据仍存各用户自己的浏览器，不建账号/云同步，留存诉求出现时再加同步层；托管 GitHub Pages + Actions 自动部署（国内访问不稳先容忍，影响使用时再镜像国内平台）；移动端先做响应式布局，PWA 作为上线后首个增量；迁移严格功能对齐不加新功能，"核心测试全绿 + 冒烟对齐"为验收线；旧单文件 `index.html` 保留至新版功能对齐后归档。

ADR-0001 的 localStorage 选型与"摩擦是督促工具第一死因"的理由仍然有效（对每位用户而言，打开网址即用）；被取代的仅是"必须单文件双击"这一交付约束。ADR-0002（历史只读）、ADR-0003（无暂停）与框架无关，继续约束新实现。
